# 本轮评审：Token 认证设计

## 对照表

| 关注点 | 方案结论 | 产出 |
|---|---|---|
| 认证位置 | `loop_server` 的 WebSocket 握手阶段，在创建 `BotContext` 前校验 | `doc/websocket-token-auth.md` |
| 凭据格式 | `Authorization: Bearer <token>` | `doc/websocket-token-auth.md` |
| 默认行为 | 未配置 token 时维持现有无认证连接 | `doc/websocket-token-auth.md` |
| 失败行为 | 配置 token 后缺失/格式错误/错误 token 均以 401 拒绝 | `doc/websocket-token-auth.md` |
| 安全约束 | 凭据不进日志；生产使用 TLS；避免 Debug 泄漏 | `doc/websocket-token-auth.md` |
| 兼容影响 | 扩展公开 `BotServer` 字段可能影响 struct literal 调用方 | `doc/websocket-token-auth.md` |

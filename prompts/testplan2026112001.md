### 集成测试环境与方法

最小环境是同一机器上的 runbot 服务端、可控 WS 客户端，以及用于验证 `loop_client` 的可控上游。无需数据库、容器或真实 OneBot 服务。自动化夹具未来如何实现属于后续工作，本次只定义其能力要求。

1. 内存握手测试复用标准有效 Upgrade 请求，修改 Authorization 数据；读取完整状态行、响应头及声明长度的响应体，不能只检查首行。
2. 真实 TCP 测试绑定 `127.0.0.1` 的可用端口；可控 listener 可使用端口 0 并读取实际端口。`loop_server` 不暴露 listener 地址，测试需先选择可用端口，启动后以有截止时间的探测确认就绪；遇到端口竞争重选，不能将其误判为认证失败。
3. 上游夹具需支持：记录握手请求、按序返回 401/403/500/101、成功后主动断开、接收和回送合法 OneBot 消息。请求记录中的测试凭据只在进程内断言，不直接写入测试报告。
4. 正常握手/消息等待上限建议 3 秒；shutdown 等待上限 2 秒。客户端既有重连等待为 15 秒：从失败/断开完成时刻计时，允许调度误差，第二次握手最晚 20 秒内出现，连续三次尝试总超时 45 秒。确认等待期没有忙重试。
5. 当前 Tokio 未启用 `test-util`，不假定可直接暂停时间；未来若引入虚拟时间须另行配置。本计划默认用真实时间验证重连。
6. `loop_server` 没有公开停服接口；测试结束需由夹具取消主循环并结束全部对端/连接任务，或使用独立进程整体退出。不能只中止 accept 任务就认定派生连接任务已清理。
7. 每例独立配置与端口，关闭所有客户端、listener 和后台任务，回收连接后再开始下一例。并发用例使用计数器及任务结果验证，不以固定短暂 sleep 代替就绪同步。

真实 OneBot 联调是可选补充：执行方已有环境时记录其版本、WS 方向和 Token 注入方式，复验同 Token 成功、错 Token 拒绝及一条消息闭环；没有该环境时，使用上述本机可控对端完成必测项，并注明尚无真实产品互通结论。

## UT 测试用例

本节为 Given–When–Then 计划摘要，详细参数和覆盖状态以 [测试用例文档](../doc/websocket-token-auth-testcases.md) 为准。现有测试与新增测试均已在 [集成测试报告](it2026112001.md) 中记录执行结果。

### `runbot/src/bot_context.rs`

#### U-B01～U-B03：配置默认、保存及空值

- **Given**：分别使用服务端和客户端 builder，提供其有效基础配置。
- **When**：不调用 Token 配置、设置普通 Token、设置空字符串并 build。
- **Then**：依次得到未启用认证、原样保存 Token、`ParamsError`；错误中没有凭据。

#### U-B04～U-B06：重复配置、既有参数和 Debug

- **Given**：builder 接收两次不同 Token，或缺失既有必需参数，或构建待格式化对象。
- **When**：build、启动客户端校验 URL，或打印普通/展开 Debug。
- **Then**：最后一次 Token 生效；服务端缺 bind 在 build 时失败，客户端缺 URL 在 `loop_client` 时失败；Debug 仅输出脱敏标记。

### `runbot/src/connection.rs`

#### U-A01～U-A06：Authorization 解析

- **Given**：配置预期 Token，准备大小写变体、缺失、畸形、错误 scheme、不匹配及不可转为字符串的头值。
- **When**：调用认证检查。
- **Then**：只有正确 Bearer 及精确匹配 Token 通过；scheme 大小写不敏感，Token 大小写敏感；其余返回对应失败类别。

#### U-A07～U-A09：比较、拒绝响应及关闭认证

- **Given**：不同长度/内容字节串、认证失败或未启用认证。
- **When**：比较、生成拒绝响应或执行握手回调。
- **Then**：比较结果正确；拒绝响应字段和固定正文完整；未启用时不校验 Authorization。

#### U-C01～U-C05：出站请求

- **Given**：有效 URL，无/有 Token、非法 Token 或非法 URL。
- **When**：构造握手请求。
- **Then**：按配置决定是否携带唯一敏感 Bearer 头；保留 Upgrade 必需字段与路径/query；非法配置返回错误，Token 不进入 URI、Debug 或错误内容。

| 层次 | 编号 | 验证内容 |
| --- | --- | --- |

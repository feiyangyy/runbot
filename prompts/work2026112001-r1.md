## 实施落地（按 doc/websocket-token-auth.md）

- `runbot/src/bot_context.rs`
  - `BotServerBuilder::access_token` 新增可选 token 配置。
  - `BotServer` 增加私有 `access_token` 字段，并实现脱敏 `Debug`。
  - `build` 拒绝空 token。
- `runbot/src/connection.rs`
  - `loop_server` 改用 `accept_hdr_async`，在创建 `BotContext` 前校验 `Authorization: Bearer <token>`。
  - 未配置 token 时保持开放连接；缺失、格式错误、scheme 不匹配或 token 错误返回 401。
  - 认证失败不终止接入循环，后续连接继续接受；握手失败不再 `unwrap` panic。
  - 常量时间比较 token，日志只记录失败类别，不记录凭据。
- `runbot/examples/server.rs`、`README.md`
  - 示例通过环境变量可选启用 token，并说明 OneBot 客户端配置及明文 WS 风险。
